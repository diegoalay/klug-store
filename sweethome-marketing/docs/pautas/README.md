## Aprendizajes acumulados

1. **El costo por conversación es bajo** ($0.95), pero se desconoce cuántas de esas conversaciones terminaron en venta: el centro de clientes potenciales no tiene a nadie en "Calificado" ni "Convertido" ([diagnóstico](../diagnostico-2026-10-04.md)).
2. **El público (edad, sexo, ubicación) no está disponible todavía** en Business Suite para este anuncio.
3. **La pauta se corrió desde la herramienta de "Anuncios" simples, no desde el Administrador de anuncios completo.** Para tener públicos guardados, retargeting y mejor control de presupuesto habría que configurar una cuenta publicitaria propiamente.
